GN Tools — приложение для Windows
=================================

Одна программа, четыре инструмента:
1. WhatsApp, Instagram и Telegram → Excel: приложение открывает сервис, читает доступные вам диалоги и заполняет общую базу контактов.
2. База контактов: поиск и просмотр записанных строк прямо в GN Tools.
3. Документы на отгрузку: упаковочный лист, ТТН (1-Т), ТН (ТОРГ-12), CMR.
4. Конвертер таблиц: XLSX ↔ XLS ↔ CSV (все 6 направлений, локально и бесплатно).

Скорость (v4.3)
---------------
Excel больше не перечитывается на каждую строку — книга держится в памяти.
Скан чатов ждёт синхронизацию 8 сек вместо 60, пауза между чатами короче,
новые сообщения обрабатываются через 12 сек, а не 90.

Аккаунт общий с сайтом https://gnfintrust.github.io — те же почта и пароль.

Как запустить
-------------
1. Распакуйте GNTools-client.zip в любую папку.
2. Запустите GNTools.exe (Windows может предупредить про неизвестного издателя — «Подробнее» → «Выполнить в любом случае»).
   Если GN Tools уже установлен, мастер предложит обновить без полной переустановки.
3. GN Tools откроется как отдельное окно приложения. Системный браузер используется внутри в режиме приложения, без обычной адресной строки.
4. Войдите или создайте аккаунт — пробные использования начислятся автоматически.

Файлы рядом с exe
-----------------
- GNTools.exe — сама программа
- config.txt — настройки (ключи API, Firebase, количество пробных использований)
- база ватсап ии.xlsx — общая база WhatsApp, Instagram и Telegram
- LICENSE — лицензия MIT для исходного кода

Покупка доступа
---------------
На сайте https://gnfintrust.github.io/gntools.html можно купить пакет использований или подписку. После оплаты нажмите «Я оплатил(а)» — админ проверит и включит доступ. Перезапустите программу или выйдите/войдите снова.

Админам
-------
- Чтобы выдать бесплатный тест: в config.txt настройте TRIAL_TOKENS (по умолчанию 3).
- Чтобы сделать сотрудника админом: поставьте поле admin=true в документе users/{uid} в Firestore.
- Чтобы изменить цены или ссылку на скачивание: используйте вкладку «GN Tools» в админке сайта.
- Обязательно обновите Firestore rules (файл firestore.rules) в консоли Firebase.

Сборка exe
----------
Запустите build_exe.bat на Windows с установленным Node.js. Он создаст GNTools.exe и GNTools-client.zip.

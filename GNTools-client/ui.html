WhatsApp / Instagram / Telegram

  1. Выберите источник и модель ИИ (цена зависит от модели).
  2. WhatsApp: браузер + Excel → QR-код.
  3. Telegram: токен бота из @BotFather → запустить.
  4. Instagram: скопировать переписку → вставить → обработать.

База

  1. После сканирования откройте вкладку «База» — там все записанные контакты.
  2. Ищите по имени, телефону или компании. «Открыть в Excel» запускает файл на компьютере.

Документы

  1. Выберите Базовое (1 токен) или AI (Haiku 2 / Opus 3 токена).
  2. Открыть → заполнить Данные → печать Ctrl+P.

# Видеоуроки GN FinTrust (Remotion)

Обучающие ролики с анимированной графикой: ЭСФ, НДС и бухгалтерия с формулами.
Программа уроков, факты и источники — в [PROGRAM.md](PROGRAM.md).

| Ролик | Тема | Длина |
|---|---|---|
| `Esf1-WhoMust` | ЭСФ: что это и кто обязан | ~49 с |
| `Esf2-HowTo` | Как выписать ЭСФ за 6 шагов | ~51 с |
| `Vat-Formulas` | НДС 12%: три формулы | ~46 с |

Формат 9:16, 1080×1920, 30 кадров/с, без звука — музыку и голос добавьте при монтаже (CapCut, Instagram).

## Запуск

Нужен Node.js 18+.

```bash
cd video
npm install
npm run studio     # редактор с предпросмотром в браузере
npm run render     # все ролики → out/*.mp4
```

Один ролик: `npx remotion render src/index.ts Vat-Formulas out/Vat-Formulas.mp4`.

## Как устроено

- `src/ui.tsx` — шрифты и цвета сайта, общие блоки: заголовок, карточка, формула, счётчик, рамка урока с прогрессом.
- `src/timeline.tsx` — сцены подряд: `[длительность в кадрах, (dur) => <Сцена/>]`.
- `src/videos/*.tsx` — по файлу на ролик. Тексты и цифры правятся прямо там.
- Новый ролик: скопируйте файл из `src/videos`, поменяйте сцены и добавьте `<Composition>` в `src/Root.tsx`.

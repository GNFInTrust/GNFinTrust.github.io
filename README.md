# GN FinTrust

Сайт вебинаров, семинаров и курсов по финансам и бухгалтерии.

Сайт: https://gnfintrust.github.io

Made by [losdek](https://github.com/tipilek2020-ai).

Вопросы — через WhatsApp, Telegram или почту, контакты на сайте.

## Как назначить админа

Панель админа (`admin.html`) открывается только тем, у кого в Firestore в записи пользователя стоит `admin: true`. Сайт сам этот флаг никому не ставит: при первом входе каждому создаётся запись с `admin: false`.

### Первый админ (через консоль Firebase)

1. Зайдите на сайт через страницу входа (`login.html`) тем аккаунтом, который должен стать админом. Так в базе появится запись пользователя.
2. Откройте [консоль Firebase](https://console.firebase.google.com/) и выберите проект **fintrust-af741**.
3. Перейдите в **Firestore Database** → вкладка **Данные** → коллекция **`users`**.
4. Найдите документ нужного пользователя. Его ID совпадает с UID аккаунта; проще всего найти по полю `email`. UID также виден в разделе **Authentication** → **Users**.
5. Нажмите на поле `admin` и поменяйте значение с `false` на `true` (тип — boolean, не строка `"true"`). Если поля нет, добавьте его: имя `admin`, тип `boolean`, значение `true`.
6. Вернитесь на сайт и обновите страницу. В меню появится кнопка «Админ». Если её нет, выйдите и войдите снова.

### Следующие админы (из панели)

Когда первый админ есть, остальных можно назначать прямо на сайте: **Админ** → вкладка **«Аккаунты»** → кнопка **«Сделать админом»** рядом с пользователем. Пользователь должен хотя бы раз войти на сайт, чтобы появиться в списке.

### Как снять права

В консоли Firebase поменяйте `admin` у пользователя обратно на `false` (в панели кнопки для этого нет).

### Важно про безопасность

Флаг `admin` проверяется в браузере, поэтому настоящую защиту дают только правила безопасности Firestore. В них должно быть запрещено, чтобы пользователь сам ставил себе `admin: true`, а читать и менять заявки, цены, оплату и чужие аккаунты разрешено только админам.
